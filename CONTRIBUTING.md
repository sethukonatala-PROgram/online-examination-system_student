# Contributing to ExamPulse

Thank you for contributing to **ExamPulse - Smart Online Examination & Assessment System**! This repository is designed for academic excellence in Computer Science & Engineering.

## Contribution Workflow

1. **Fork the Repository**: Click Fork on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/sethukonatala-PROgram/student_management_system.git
   cd student_management_system
   ```
3. **Create a branch**:
   ```bash
   git checkout -b feature/new-question-bank
   ```
4. **Make changes**: Follow clean enterprise code styling in `assets/css/style.css` and vanilla ES6 modular JavaScript.
5. **Test locally**:
   - Run `python server.py --port 8080` or open `index.html`.
   - Test test-taking flows, timer countdown, question palette states, and proctoring alerts.
6. **Commit & Push**:
   ```bash
   git commit -m "feat: add operating systems memory management questions"
   git push origin feature/new-question-bank
   ```
7. **Submit a Pull Request**.
